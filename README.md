# 陈禹铮个人作品集 V1.1

## 直接预览
双击 `index.html` 即可在浏览器打开。

## 文件说明
- `index.html`：网页主体
- `style.css`：样式
- `script.js`：岗位视角筛选交互
- `assets/`：后续放照片、项目截图、二维码等
- `resume.pdf`：后续把你的正式简历 PDF 放到此文件夹，并命名为 `resume.pdf`

## 第一版需要你后续替换的内容
1. 电话（如准备公开）
2. 正式简历 PDF
3. 个人照片（可选）
4. 项目截图 / 系统截图（需脱敏）
5. 论文、DOI、专利等公开科研证明
6. 最终个人域名

## 推荐开发方式
用 VS Code 打开整个文件夹。
修改后保存，刷新浏览器即可看到效果。

## 后续部署
V1.1 已部署到 GitHub Pages，后续可持续更新。
正式求职前建议绑定个人域名。
